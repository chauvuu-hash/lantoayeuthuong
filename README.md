# Ánh sáng Công nghệ – Lan tỏa yêu thương

Trang web giới thiệu Dự án Nhân ái "Ánh sáng Công nghệ" (Đinh Diệu Anh – SBD 186, Hoa hậu Việt Nam 2026), thí điểm tại Làng trẻ em SOS Hải Phòng.

- Trang tĩnh một file: `index.html` (không cần build).
- Bật GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
- Các thông tin chưa chốt (liên hệ, số liệu hiện trạng, câu chuyện của các em, đối tác…) sẽ được bổ sung dần.
